# Specification Template

## 1. Objective
Describe the business goal and the user or system outcome this sprint is trying to achieve.

## 2. Scope
List the clear boundaries of the task.
- In scope:
- Out of scope:

## 3. Constraints
Document known constraints, standards, or architecture requirements.
- architecture constraints
- security constraints
- data constraints
- performance constraints
- required patterns

## 4. Acceptance Criteria
Write the acceptance criteria as GIVEN / WHEN / THEN scenarios.

### AC-01
GIVEN ...
WHEN ...
THEN ...

### AC-02
GIVEN ...
WHEN ...
THEN ...

## 5. Validation Requirements
List how success will be verified.
- tests to run
- business checks
- architecture checks
- event or integration checks

## 6. Risks and Dependencies
Document risks, blockers, external dependencies, and known assumptions.

## 7. Definition of Done
List the conditions that must be true before the sprint is considered complete.
